# MolLabs Restaurante 

Proyecto full-stack para la gestión de un restaurante, desarrollado con:

- **Laravel** (Backend API)
- **React + Vite** (Frontend)
- **MySQL** (Base de datos)

## Funcionalidades principales
- Listado de productos
- Carrito de compras
- Gestión de pedidos
- Panel de administración
- Diseño responsive
