Sistema de Pedidos - Restaurante MolLabs
Este proyecto es una aplicación web diseñada para la gestión de ventas y pedidos en un restaurante. El sistema permite visualizar un menú organizado por categorías, gestionar un carrito de compras con validación de inventario y registrar órdenes de venta de forma automática.

Características principales:
Menú Dinámico: Clasificación de platos en categorías como Italiana, Asiática y Bebidas.

Gestión de Stock: El sistema descuenta automáticamente las unidades del inventario tras cada venta y bloquea productos agotados.

Interfaz Profesional: Diseño full-width responsivo que permite su uso en computadores de escritorio y dispositivos móviles.

Arquitectura Moderna: Desarrollado utilizando Laravel para el manejo de la API y React para una experiencia de usuario fluida y rápida.

Estructura del Proyecto:
Backend: Carpeta raíz (Laravel), donde se gestiona la base de datos, las migraciones y la lógica de negocio.

Frontend: Carpeta mollabs-frontend (React), que contiene toda la interfaz visual y la conexión con el servidor.
